# seac-emergency-decision-support
Supplementary data and code for the SEAC emergency decision-support framework

## Knowledge graph and clause-level evidence store

Versioned data packages and restoration instructions are available in [data/processed](data/processed/README.md) and the [data release](https://github.com/drinkaBeer/seac-emergency-decision-support/releases/tag/data-v1.0.0). API services and credentials are not included.
